# Будущий соревновательный режим — зафиксированные решения

Статус: **только документация**. Сетевой код, сервер, синхронизация, запись повторов и интерфейс мультиплеера
сейчас НЕ реализуются.

## Правила соревнования
- Каждый участник получает **ровно три попытки**.
- Засчитывается **лучший результат из трёх**.
- **Мгновенный рестарт недоступен**: кнопка «ЗАНОВО» скрыта, клавиша R и Retry посреди попытки не работают;
  прерывать попытку нельзя, каждая из трёх доигрывается до конца.
- Игроки **не делят один физический мир**: каждый играет свою попытку локально, со своей физикой.

## Тень соперника
- Вместо живого соперника показывается **полупрозрачная тень лучшей попытки противника**.
- Тень воспроизводит **записанные движения** противника (позиции/повороты модулей по времени).
- Тень **не имеет коллизий** и **никак не влияет** на физику игрока (только отрисовка).
- Такой подход позволяет **асинхронные** соревнования: соперникам не нужно играть одновременно.

## Что уже подготовлено в коде
- `GameManager.allow_instant_restart` (export, по умолчанию `true`). В соревновательном режиме — `false`:
  `restart_attempt()` отказывает, а `UIController.restart_enabled = false` полностью скрывает кнопку «ЗАНОВО».
- Вся логика рестарта проходит через одну точку — `GameManager.restart_attempt()` → `start_run()`.
- Прерванная попытка не записывается; завершённая записывается ровно один раз (`StatsStore.record_attempt`
  с уникальным id попытки) — основа для подсчёта «3 попытки, лучшая засчитывается».
- Детерминированная физика при одинаковом вводе (проверено автотестами: одинаковые попытки дают одинаковую
  дистанцию) — полезно для проверки честности записей, но **не** является сетевой синхронизацией.

## Открытые вопросы на будущее (не решены)
- Формат записи тени (частота кадров, какие узлы писать, сжатие) и её размер.
- Хранение и обмен записями (сервер / файлы / мессенджеры), защита от подделки результатов.
- Влияние пользовательских настроек (скорости вращения, неуязвимость) на честность соревнования —
  вероятно, в соревновании нужны фиксированные значения.
- Отображение тени: прозрачность, цвет, что делать после отрыва конечностей и реактивной головы.

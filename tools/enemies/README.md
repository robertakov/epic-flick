# Normal enemy assets

Requires Python with Pillow, NumPy, SciPy and PyAV. Run extract.py, faces.py, profiles.py, tune.py, roster.py in that order. Raw Characters/Enamies sources are preserved locally and ignored by Git. Runtime does not decode video or process pixels. Output reports go to reports/v19_processing. Enemy profiles affect presentation only; original physical archetypes remain authoritative. The alternate Cowboy sheet is deliberately unused.
